A tiny program that ships one funny patch note for a bug in real life: hiccups that refuse to respect the mute button.

## Run it

```sh
python3 main.py
```

The program writes the entry line to `$MAKEFUN_OUTPUT_DIR/entry.txt`, or to `/tmp/out/entry.txt` when that variable is not set.
